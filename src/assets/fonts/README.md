# Inter

Inter Variable 4.1, normal, poids 100 à 900, distribué avec le launcher pour que
le premier affichage ne dépende d'aucune feuille de style ou police distante.
`font-display: swap` garde la police système disponible pendant son chargement.

Source : <https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1>.
Projet : <https://rsms.me/inter/>. Licence SIL Open Font License 1.1 distribuée dans
